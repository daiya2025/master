# PLATEAU Chiyoda LOD2 capture

Automated browser capture of the official Project PLATEAU Chiyoda-ku 2025 LOD2 building 3D Tiles.

- Source dataset: `13101-bldg-lod2-2025`
- Renderer: CesiumJS
- Output: 60-second 1920x1080 MP4

This repository contains only capture scripts and references public PLATEAU distribution endpoints at runtime.
